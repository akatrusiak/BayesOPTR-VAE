# VAE Project

This directory contains the core implementation of the Variational Autoencoder (VAE) model

## Contents

- `data.py`: Data loading and preprocessing utilities
- `encoder.py`: VAE encoder implementation
- `decoder.py`: VAE decoder implementation
- `model.py`: Main VAE model architecture
- `train.py`: Training script for the VAE
- `surrogate.py`: Surrogate model implementation
- `train_surrogate.py`: Training script for surrogate models
- `verify_dz.py`: Verification scripts for latent dimension analysis
- `diagnose_verify.py`: Diagnostic tools for verify_dz.py
- `compare_latent_signal.py`: functional validation of VAE with surrogate
- `runs/`: Directory containing trained model checkpoints and experiment results

## Usage

Refer to individual Python files for specific usage instructions. Training and evaluation scripts are provided for both the VAE and surrogate models.
